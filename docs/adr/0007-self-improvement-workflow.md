# ADR-0007: 에이전트 자기 개선 구조 (제안 → 승인 → 자동 반영)

- 상태: 승인
- 날짜: 2026-11-21
- 관련: ADR-0002, ADR-0005, ADR-0006, ADR-0008, I-14, I-17, I-18, I-19, I-20, I-21

## 배경
Slack 으로 에이전트를 쓰면서 프롬프트 개선, 에이전트 정의 수정, 새 MCP 서버 추가 같은 변경이 필요해진다.
이 변경을 에이전트가 직접 만들고 반영할 수 있어야 한다.

## 검토한 대안
- **에이전트가 직접 수정·배포**: 가장 빠르지만, 에이전트가 자신을 망가뜨리면 복구 경로가 사라지고 권한 상승을 막을 수 없다. → 기각.
- **에이전트는 변경을 제안하고, 소유자 승인 후 외부 시스템이 반영**: 채택.
- **범위를 단계적으로 개방**(프롬프트 → 정의 → 코드): 검토했으나, 소유자 결정으로 **처음부터 전체 범위를 개방**한다.

## 결정

### 변경 대상별 경로

| 변경 대상 | 원본 | 경로 |
|---|---|---|
| 프롬프트·모델·파라미터 | Langfuse | 새 버전 작성(`candidate` 라벨) → 평가 → Slack 승인 → `production` 라벨로 승격 |
| 에이전트 정의 | git | 브랜치 → PR → 소유자 승인 → 머지 → GitOps 배포 |
| 코드 (새 MCP 서버 등) | git | 브랜치 → 검사 통과 → PR → 소유자 승인 → 머지 → 이미지 빌드 → GitOps 배포 |

### 구성
- **실행용 에이전트**: Slack 에 응답한다. 변경 요청이면 개발 에이전트에 위임만 한다. git 쓰기·클러스터 쓰기 권한이 없다 (I-17).
- **개발 에이전트**: 격리된 Pod(작업마다 새로 생성)에서 실행한다. Claude 엔진을 쓰며, 셸·파일 편집 도구가 이 에이전트 정의에만 허용된다 (I-14).
  - 가진 권한: 저장소 브랜치 push 와 PR 생성, Langfuse 프롬프트의 비-`production` 버전 생성.
  - 갖지 않는 권한: `main` 직접 push, PR 승인·머지, `production` 라벨 변경, 클러스터 접근, Secret 생성.
- **배포**: 에이전트가 아니라 GitOps 컨트롤러가 수행한다 (ADR-0008, I-18).

### 안전장치
1. **소유자 승인 필수**: `production` 프롬프트 승격과 `main` 머지는 소유자만 승인한다. 에이전트는 자기 변경을 승인할 수 없다 (I-19).
2. **별도 신원**: 개발 에이전트는 소유자 계정이 아닌 **별도 GitHub 신원(GitHub App)** 으로 PR 을 만든다. 소유자 계정으로 PR 을 만들면 소유자가 자기 PR 을 승인할 수 없어 승인 절차가 성립하지 않는다.
3. **보호 경로**: 다음 경로를 바꾸는 에이전트 PR 은 CI 에서 실패시킨다 (I-20). (ADR-0024 로 대체: 막지 않고 민감 경로로 표시해 강화된 승인을 받는다.)
   - `docs/architecture/invariants.md`, `docs/adr/`
   - `.github/` (CI 설정, CODEOWNERS)
   - 개발 에이전트 자신의 정의 파일과 승인 절차 코드
4. **비밀값은 사람만**: 새 Secret 이 필요하면 에이전트는 생성 방법을 안내만 한다 (I-21).
5. **자동 롤백**: 배포 후 상태 확인에 실패하면 이전 버전으로 되돌린다. 프롬프트는 라벨을 이전 버전으로 되돌린다.
6. **실행 빈도 제한**: 개발 에이전트 작업에 동시 실행 수와 일일 횟수 제한을 둔다 (ADR-0002 의 "일반적 개인 사용" 범위 유지).

## 결과
- Slack 대화만으로 프롬프트, 정의, 코드 변경을 요청하고 승인할 수 있다.
- 에이전트가 오작동해도 롤백과 복구 경로가 에이전트 바깥에 남는다.
- GitHub App, 브랜치 보호 규칙, CI 보호 경로 검사, GitOps 컨트롤러, 평가 파이프라인이 필요하다.

## 재검토 조건
- 승인 대기가 병목이 될 때 → 저위험 변경(예: 평가 점수가 기준 이상인 프롬프트)의 자동 승격 검토.
- 보호 경로 우회 시도가 관측될 때.
