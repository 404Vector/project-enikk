# ADR-0010: enikk-core 를 제어 경로 전용 중앙 서비스로 두고 엔진별 런타임을 분리

- 상태: 승인 (§3 의 "런타임은 상태를 갖지 않는다"(I-25)는 ADR-0037 로 부분 대체: 공유 볼륨 예외)
- 날짜: 2026-11-21
- 대체: ADR-0009
- 관련: ADR-0003, ADR-0005, ADR-0007, I-11, I-12, I-22, I-23, I-24, I-25

> §3 의 "런타임은 상태를 갖지 않는다"는 ADR-0037 이 부분 대체한다. runtime 의 공유 볼륨에는 다시 만들 수 있는 것(저장소 사본, 스냅샷, 스레드별 worktree·임시 자료)만 둔다. 작업·세션 상태는 여전히 core 에만 있다(I-25).

## 배경
- 구성요소가 Slack 커넥터, Claude 런타임, Gemini 런타임, agentgateway, 여러 MCP 서버로 늘어난다.
- 작업 상태, 스레드-세션 연결, 승인 흐름(ADR-0007), 엔진 간 위임(I-12)을 한 곳에서 관리할 필요가 있다.
- ADR-0009 는 "Slack 봇 → 큐 → 런타임" 구조로, 위 상태를 어디서 관리할지 정하지 않았다.

## 검토한 대안
- **중앙 서비스 없음**(git·Kubernetes·큐만으로 관리): 구성은 단순하지만 작업·세션·승인 상태가 여러 곳에 흩어진다.
- **모든 트래픽을 거치는 중앙 서비스**: LLM·MCP 호출까지 중계. 병목·단일 장애 지점이 되고, 구독 토큰이 중앙 서비스를 통과해 I-03 과 충돌. → 기각.
- **제어 경로 전용 중앙 서비스(enikk-core)**: 채택.

## 결정

### 구성요소

| 구성요소 | 역할 |
|---|---|
| **enikk-core** | 작업 상태 관리, Slack 스레드 ↔ 세션 ↔ 에이전트 정의 연결, 에이전트·MCP 카탈로그 제공, 승인 흐름, 엔진 간 위임 중계 |
| **커넥터** (첫 번째: Slack) | 외부 인터페이스와 연결. 이벤트를 core 에 전달하고 core 의 결과를 외부에 게시 |
| **엔진별 런타임** (Claude, Gemini) | core 가 배정한 작업을 실행하는 상태 없는 작업자. 엔진마다 별도 이미지·Pod |

### 흐름

```
 커넥터 ──이벤트──► enikk-core ──작업 배정(큐)──► 엔진별 런타임
   ▲                   ▲                              │
   └──── 결과 게시 ─────┴────────── 결과 보고 ─────────┘

 런타임 ──모델 호출(직접)──► Anthropic / Google API
 런타임 ──도구 호출──► agentgateway ──► MCP 서버들
```

### 경계 규칙
1. core 는 **제어 경로만** 다룬다. LLM 호출과 MCP 호출은 런타임이 직접 하며 core 를 거치지 않는다 (I-23).
2. core 는 설정의 **원본을 갖지 않는다.** 에이전트 정의는 git, 프롬프트는 Langfuse, 배포 상태는 GitOps 가 원본이며 core 는 읽기만 한다 (I-24).
3. 런타임은 **상태를 갖지 않는다.** 작업·세션 상태는 core 와 그 저장소에만 있다 (I-25).
4. 커넥터는 에이전트를 실행하지 않고 core 와만 통신한다. 런타임은 core 가 배정한 작업만 실행한다 (I-22).
5. 엔진 간 위임은 core 가 부모 작업 → 자식 작업으로 중계하며, 명시적인 입력·출력만 넘긴다 (I-12).

## 결과
- 커넥터를 추가해도(웹, 다른 메신저) 런타임은 바뀌지 않는다. 엔진을 추가해도 커넥터는 바뀌지 않는다.
- 런타임을 자주 재배포해도 진행 중인 작업 상태가 사라지지 않는다 (ADR-0007 의 잦은 배포와 맞음).
- 상태 조회, 작업 취소, 승인 같은 관리 기능을 core API 하나로 제공하고 Slack 명령과 향후 관리 화면이 함께 쓴다.
- core 가 중요한 단일 지점이 된다. core 가 멈추면 새 작업을 받을 수 없다. → core 는 작게 유지하고 상태는 외부 저장소에 둔다.

## 후속 결정
- 상태 저장소, 작업 큐, API 형식, 서비스 간 인증: ADR-0011.
