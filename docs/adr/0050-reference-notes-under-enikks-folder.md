# ADR-0050: 에닉의 폴더 아래에 '자료' 층을 둔다

- 상태: 승인
- 날짜: 2026-11-28
- 관련: ADR-0028(§2·§4 를 보탬), ADR-0049, I-35

## 배경
소유자는 니케 전체(약 210명)를 정리해 두고, 뒤에 에이전트 캐릭터를 고를 때 쓰고 싶어 한다(2026-11-27, 스레드 94bec15f). 구조는 두 겹이다. 이름과 한 줄 설명을 담은 인덱스 노트가 있고, 인덱스에서 니케마다 하나씩 있는 상세 노트로 들어간다.

지금의 기억 도구로는 이렇게 둘 수 없다.
- `remember` 는 `선호`·`사실`·`진행 중` 세 폴더에만, 하위 폴더 없이, 한 노트에 1,000자까지 쓴다.
- 이 세 폴더의 노트는 모든 작업에 함께 간다(합쳐 4,000자, ADR-0028 §3). 큰 자료를 넣으면 다른 기억이 밀려난다.
- `write_note`(ADR-0049)는 `Private/` 밖에만 쓴다.
- 도구 인자로 노트 본문을 하나씩 넘기면 수백 개 노트가 모델의 맥락을 다 채운다.

## 검토한 대안
- **A. 공개 쪽 폴더에 `draft: true` 로 둔다**: 지금 바로 된다 / 블로그 볼트에 블로그와 상관없는 자료가 섞이고, 실수 한 번에 공개될 수 있다. → 기각.
- **B. `remember` 를 넓힌다(하위 폴더, 긴 본문)**: 도구가 하나로 남는다 / 기억(작업마다 붙는 것)과 자료(찾아 읽는 것)의 구분이 흐려진다. → 기각.
- **C. 에닉의 폴더에 `자료/` 를 두고 `write_note` 로 쓴다. 본문은 스레드 작업 공간의 파일에서 읽는다**: 기억과 자료가 폴더로 나뉜다. 쓰기 확인은 `write_note` 의 것을 그대로 쓴다. → 채택.

## 결정
### 1. 자료 층
- `vault/Private/enikk/자료/` 아래 어느 깊이에든 `.md` 노트를 둘 수 있다(숨김·상대 경로 조각은 안 됨).
- 자료 노트는 색인되어 `recall` 로 찾고 `read_note` 로 읽는다. 종류는 `note` 라서 작업마다 붙는 기억(`선호`·`사실`·`진행 중`)에 들지 않는다.
- 노트 사이 연결은 Obsidian 위키 링크(`[[이름]]`)로 한다. 인덱스 노트가 상세 노트를 가리킨다.

### 2. 쓰기
- `write_note` 가 자료 노트도 쓴다. 확인은 ADR-0049 §2 와 같다: 소유자가 Slack 에서 시작한 작업, 비밀값 검사, 경로.
- 자료 노트는 `Private/` 아래라 공개되지 않지만, 기억 노트처럼 항상 `draft: true` 를 가져야 한다(ADR-0028 §2 의 두 겹 방어).
- 커밋 메시지는 `reference: created|updated <이름>` 이고, 초안이므로 CI 를 건너뛰는 표시를 붙인다.

### 3. 파일에서 쓰기
- `write_note` 는 `text` 대신 `file`(이 스레드의 worktree·tmp 안의 파일)을 받을 수 있다. 엔진이 그 파일을 읽어 core 에 보낸다. 파일 위치 확인은 `send_file` 과 같다(ADR-0042).
- `write_notes` 는 `{path, file}` 을 50개까지 받아 차례로 쓰고, 처음 거부된 곳에서 멈추며 어디까지 썼는지 알린다.

## 근거
- 기억은 "작업마다 함께 가는 짧은 맥락", 자료는 "찾아 읽는 긴 참고"로 성격이 다르다. 폴더로 나누면 기존 기억의 자리를 지키면서 자료를 얼마든지 늘릴 수 있다.
- 새 권한이나 토큰이 없다. 경로 판정 하나와 엔진의 파일 읽기만 더한다.

## 결과
- I-35 가 바뀐다: 에닉의 폴더 안에서도 `자료/` 는 작업마다 붙지 않는 참고 노트 자리다.
- 자료 노트의 삭제는 아직 없다. 지울 일이 생기면 `forget_memory` 를 넓히거나 블로그 담당 에이전트의 삭제(승인 아래)에 맡긴다.
- 노트가 많아지면 볼트의 트리 응답이 커진다. core 는 트리가 잘리면 동기화를 멈춘다(`VaultReader.files`). 수천 개 규모가 되면 다시 본다.

## 재검토 조건
- 자료가 수천 개를 넘거나 동기화가 느려질 때.
- 자료를 공개 블로그로 옮기고 싶어질 때.
