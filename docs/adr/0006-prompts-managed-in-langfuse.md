# ADR-0006: 프롬프트의 원본은 Langfuse 이며 git 에 두지 않는다

- 상태: 승인
- 날짜: 2026-11-21
- 관련: ADR-0001, ADR-0005, I-06, I-13

## 배경
에이전트 정의(ADR-0005)에 시스템 프롬프트가 필요하다. 프롬프트를 git 과 Langfuse 중 어디에서 원본으로 관리할지 정해야 한다.

## 검토한 대안
- **git 이 원본, Langfuse 는 동기화**: 코드 리뷰와 이력 관리를 그대로 쓸 수 있다. 그러나 프롬프트 변경이 코드 배포에 묶인다.
- **Langfuse 가 원본, git 에는 두지 않음**: 채택.

## 결정
- 프롬프트 본문은 **Langfuse 프롬프트 관리에만** 존재한다. git 저장소에는 프롬프트 본문을 두지 않는다 (I-13).
- 에이전트 정의 파일은 프롬프트를 **이름과 라벨(또는 버전)로 참조**만 한다.
- 런타임은 실행 시점에 Langfuse 에서 프롬프트를 가져온다.

## 근거
- LLMOps 관점에서 프롬프트는 코드가 아니라 **모델 버전과 같은 산출물**이다. 코드 배포 주기와 분리해 독립적으로 버전 관리, 승격(라벨), 평가, 롤백해야 한다.
- Langfuse 는 프롬프트 버전과 라벨을 관리하고, 각 실행 트레이스를 사용된 프롬프트 버전과 연결해 버전별 품질 비교를 할 수 있다.

## 결과
- 프롬프트 수정·승격·롤백에 코드 배포가 필요 없다.
- Langfuse 가 관측 도구를 넘어 **실행에 필수인 의존성**이 된다. Langfuse 에 접근할 수 없으면 프롬프트를 가져올 수 없다.
  → 런타임은 마지막으로 가져온 프롬프트를 캐시로 쓰고, 캐시도 없으면 실행을 거부한다(임의의 기본 프롬프트로 대체하지 않는다).
- 테스트는 가짜 `PromptStore` 를 쓴다. 테스트 코드의 더미 문자열은 실제 프롬프트가 아니어야 한다.
- Langfuse self-host 로 전환할 때(ADR-0001 재검토 조건) 프롬프트 이전 작업이 추가로 필요하다.

## 후속 확인 필요
- Langfuse Hobby 플랜에서 프롬프트 관리 기능의 한도, 그리고 "조회 기간 30일"이 프롬프트 버전에도 적용되는지.
- 프롬프트 백업 방법 (Langfuse API 로 내보내기 → git 이 아닌 별도 저장소).

## 재검토 조건
- Langfuse 장애가 실행에 자주 영향을 줄 때.
